# Gilgame studio 公式サイトを公開しました

小さな一歩から、きらめく冒険へ。個人ゲーム開発スタジオ「Gilgame studio」の公式サイトがオープンしました。作品づくりの歩みやお知らせを、この場所からお届けしていきます。

## はじめまして、Gilgame studioです

公式サイトへようこそ。Gilgame studioは、小さな「やってみたい」をゲームにする個人開発スタジオです。

発見する楽しさ、できたときのうれしさ、また会いたくなる世界。そんな体験を大切にしながら、思わず笑顔になるゲームづくりに取り組んでいます。

今回、その活動をお伝えする場所として、公式サイトを公開しました。

## ギルガメと一緒に、新しい一歩を

サイトで皆さんをお迎えするのは、水色のからだと金色の甲羅、額の青いクリスタルが目印の「ギルガメ」です。

白と水色を基調に、クリスタルの青ときらめく金色を添えたサイトには、これから始まる小さな冒険への思いを込めました。ギルガメと一緒に、気軽にのぞいてもらえる場所に育てていきたいと思っています。

## このサイトでお届けすること

- Games：制作するゲームの紹介や、作品に関する情報を掲載していきます。
- Journal：開発の進捗、制作中に考えたこと、スタジオからのお知らせをお届けします。
- About：スタジオの紹介と、ゲームづくりで大切にしていることをご案内します。

作品の紹介は、これから少しずつ準備していきます。まずはこの最初のお知らせから、ものづくりの歩みを残していきます。

## これから、どうぞよろしくお願いします

まだ小さなスタートですが、一つひとつの発見を大切に、作品とこのサイトを育てていきます。

ふと思い出したときに、また遊びに来てもらえたらうれしいです。ギルガメとGilgame studioを、どうぞよろしくお願いします。

[公式サイトを見る](https://www.gilgamestudio.com/)
